# VibeApp
================

## Project Overview
VibeApp is a full-stack JavaScript application designed to generate Flutter code and provide a preview, enabling the rapid development of Mobile App MVPs.

## Project Structure
The repository is divided into two primary directories: `backend` and `frontend`. The `backend` directory contains the server-side logic, including controllers, middleware, models, routes, and services. The `frontend` directory contains the client-side code, built using Vite and React.

## Detected Frameworks and Libraries
* Backend: Node.js, Express.js
* Frontend: Vite, React, Axios

## Setup
To get started with the project, follow these steps:

1. **Clone the repository**: `git clone https://github.com/[username]/VibeApp.git`
2. **Install backend dependencies**: `cd backend` and `npm install`
3. **Install frontend dependencies**: `cd frontend` and `npm install`
4. **Start the backend server**: `cd backend` and `node server.js`
5. **Start the frontend development server**: `cd frontend` and `npm run dev`

## Key Features
* **Flutter Code Generation**: VibeApp allows users to generate Flutter code for rapid Mobile App MVP development.
* **Preview**: The application provides a preview feature to showcase the generated Flutter code.
* **Authentication and Authorization**: The application includes authentication and authorization using `authController.js` and `authMiddleware.js`.
* **AI-powered Services**: VibeApp utilizes AI-powered services using `aiService.js`.
